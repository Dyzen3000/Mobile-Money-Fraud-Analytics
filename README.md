# Banking Transaction Fraud Analysis
Analyze Bangalore’s residential real estate market to identify high-value localities, pricing patterns, and factors influencing property prices. The project compares properties across BHK, size, type, age, amenities, and builders to identify potentially undervalued properties and estimate fair market prices for buyers and investors.

# Objectives
Compare property prices across Bangalore localities
Analyze ₹/sq.ft. across BHKs and property types
Identify factors influencing property prices
Compare builders and property characteristics
Identify potentially undervalued properties

# Key Areas of Analysis
Locality & price analysis
Property size and BHK analysis
Property age and pricing
Amenities and price premiums
Builder/project analysis
Property valuation and price prediction
